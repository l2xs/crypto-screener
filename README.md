# crypto-screener
Helps find coins with available entry points for trades

How to use
1. Install Python from python.org
2. Open Windows PowerShell
3. cd "path to screener.py"
3.1 python screener.py       # gives coins with triggers to enter trades
3.2 python screener.py --min-score 2       # see more candidates, looser bar
3.3 python screener.py --min-score 4       # only perfect convergence
3.4 python screener.py --signal       # full deterministic trade setup
